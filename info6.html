Ciclo del Agua

Proyecto hecho en Autodesk Maya 2025



Mi proyecto en Maya 3D: Nubes, lluvia y ciclo del agua

1. En este proyecto usamos Maya 3D para explicar el ciclo del agua de una forma más divertida.

2. Primero abrimos Maya y creamos una escena nueva con cielo y suelo para trabajar.

3. Para hacer las nubes no usamos esferas, usamos la herramienta FX.

4. Dentro de FX usamos nParticles para crear la nube.

5. Las nParticles son muchas bolitas pequeñas que juntas se ven como una nube.

6. Le pusimos un Emitter, que es de donde salen las partículas.

7. Con el Emitter pudimos controlar cuántas partículas salían y qué tan rápido.

8. Después le cambiamos el tamaño, el color y la forma para que se viera como nube real.

9. Para la lluvia también usamos nParticles, pero con otra configuración.

10. En la lluvia le pusimos gravedad para que las gotas cayeran hacia abajo como lluvia de verdad.

11. También le bajamos el tamaño a las partículas para que parecieran gotas.

12. Abajo pusimos un lago para que se viera donde cae toda la lluvia.

13. Y pusimos el sol para que se entendiera la evaporación del agua.

14. Al final se ve todo el ciclo: el agua sube, se hace nube, llueve y vuelve al lago.

15. Este proyecto me ayudó mucho porque así entendí mejor cómo funciona el ciclo del agua.
